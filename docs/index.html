// the live terminal

It's the actual terminal. Not a summary of it.

The host runs a headless xterm next to herdr and sends only the rows that changed. The app draws them as real text, fitted to your screen.

So you can scroll back through the whole session, pinch to change the size, search, long-press to copy and tap links. When the agent asks something, the answers turn into buttons.

  • Type straight into the pane, like you're at the keyboard.
  • tabsHop between herdr tabs. Open a shell, or start an agent in a project or a fresh git worktree.

// away from home

It tries every road at once.

The pairing QR code carries every address your computer has. The app dials all of them together, keeps whichever answers first, and switches when you change networks. You never pick one.

what the relay sees

what your phone sees

 

End-to-end encrypted on every route, relay included: a Noise-style handshake with your computer's key pinned from the QR code, then ChaCha20-Poly1305. The relay is a Cloudflare Worker you deploy to your own account, and the free plan is enough. Tailscale needs no setup at all; the host finds its address on its own.

// notifications

Or answer without opening it.

When an agent asks a question, your phone buzzes with the question and up to three of its answers as buttons. You get one when it finishes, too.

Notifications go through ntfy, so there's no Firebase and no Google account. A button can only pick an answer the agent offered. It works once, expires after 30 minutes, and does nothing if the agent has already moved on.

// setup

Three steps, then it's just your phone.

  1. Install the herdr pluginIt runs a small host in the background whenever herdr does. The host talks to herdr's local socket and only lets in phones you've paired.
    herdr plugin install zenodea/shepherd
  2. Get the appBuild it in the cloud with a free Expo account, then open the link it prints on your phone.
    git clone https://github.com/zenodea/shepherd.git && cd shepherd && npm install && npm run build:apk -w @shepherd/mobile
  3. Scan the codeherdr opens a pane with a pairing code. It works once and expires after ten minutes, so a photo of it is useless afterwards. Your phone gets its own token.
    herdr plugin action invoke shepherd.pair

You'll need herdr 0.9 or newer, Node 22.18 or newer, and a phone. Want to look around first? npm run app:demo runs the app against a pretend computer full of pretend agents. Full instructions are in the README.
