Home, Tailscale or relay.

Turn any of them off in the Shepherd window in herdr. With only Tailscale on, nothing is reachable from other networks.

End-to-end encrypted on every route, relay included (Noise handshake, ChaCha20-Poly1305). The relay is a Cloudflare Worker on your own account.

// notifications

Answer from the notification.

You get a notification when an agent asks something or finishes, with its answers as buttons. It comes from your computer over the same encrypted connection. No Firebase, no push service.

On the lock screen it asks for your fingerprint first. The home-screen widget can answer too.

Setup.

  1. Install the herdr pluginIt starts a small host whenever herdr runs.
    herdr plugin install zenodea/shepherd
  2. Get the appInstall the APK from the latest release, or build it yourself (see the README).
    github.com/zenodea/shepherd/releases/latest
  3. Pair your phoneScan the code. It works once and expires after ten minutes.
    herdr plugin action invoke shepherd.pair

Needs herdr 0.9+, Node 22.18+ and a phone. To try the app without a computer: npm run app:demo. Details in the README.
